Sandbox Shell execution

Workspace: ...
Shell runs in a throwaway container without root or a writable system disk. The workspace is mounted at /workspace; access scopes are mounted at /scopes/<name>. Allow network lets the container reach your LAN and the internet; keep it off unless the task needs it. Requires Docker Desktop + WSL2 (Windows) or Docker Engine.

Access permissions sandbox scopes

These are host folders (Windows paths or NAS shares), not paths inside the sandbox. The model accesses them by host path; the Docker shell sees them at /scopes/<name>. ro is read-only; rw allows writes. File tools enforce the same modes. Keep scopes outside the workspace; the workspace itself is read-write.
