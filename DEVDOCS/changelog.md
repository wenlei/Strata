# 变更日志

## 2026-11-26 — Agent sidecar 恢复和 8080 首响应观测

监听器监督自己启动的 sidecar，在进程退出后按退避重试，并对外部管理的实例保留原有所有权。过期的外部端口缓存可提前失效，已发送的请求不会因为恢复而重放。鉴权的 `/metrics` 在 `http_connections` 中给出接受连接数、发送首个响应头前关闭数、错误数及耗时分布。

此前手机端曾分别出现 TCP 建连超时和代理返回 502。现场需将手机请求时间、所选入口与同一窗口内的服务日志和指标增量对时。本轮恢复测试运行在隔离监听器，线上服务仍使用原版本。

在干净候选上运行服务端、指标、子进程恢复和分块 HTTP 回归，共 372 项，369 项通过、3 项跳过。配套部署模板另通过 5 项恢复回归。
